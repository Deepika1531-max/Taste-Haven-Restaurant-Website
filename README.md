# 🍽️ Taste Haven – Restaurant Website

Welcome to **Taste Haven**, a modern and attractive restaurant website designed to provide visitors with an enjoyable online dining experience. The website showcases delicious food, restaurant information, menu highlights, and a welcoming atmosphere through an elegant and user-friendly interface.

The project focuses on creating a visually appealing restaurant website with an organized layout, attractive food imagery, and responsive design.

## 🌟 Project Overview

Taste Haven is a restaurant website that represents a modern dining destination. It allows visitors to explore the restaurant, discover food offerings, learn about its services, and find essential restaurant information.

The website combines appealing visuals, clean typography, and a consistent design to create an engaging browsing experience.

## ✨ Key Features

- **Modern Homepage:** Attractive landing page with restaurant branding and welcoming content.
- **Food Menu:** Organized presentation of different food items and categories.
- **Food Gallery:** Attractive food photography to showcase delicious dishes.
- **About Us:** Information about the restaurant, its identity, and dining experience.
- **Special Offers:** A dedicated area to highlight special dishes and promotional offers.
- **Contact Section:** Restaurant contact information for visitors.
- **Responsive Design:** Layout designed to work across desktop, tablet, and mobile screens.
- **User-Friendly Navigation:** Simple navigation to help visitors explore different website sections.
- **Attractive UI:** Beautiful colors, typography, images, and visual elements.

## 🛠️ Technologies Used

- **HTML5** – For creating the structure and content of the website.
- **CSS3** – For styling, layouts, animations, and responsive design.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/Deepika1531-max/Taste-Haven-Restaurant-Website.git
```

**2. Open the project folder**

```bash
cd Taste-Haven-Restaurant-Website
```

**3. Extract the ZIP file**

If the website source code is inside the ZIP archive, extract it into the project folder.

**4. Run the website**

Open the `index.html` file in your browser or use the Live Server extension in Visual Studio Code.
